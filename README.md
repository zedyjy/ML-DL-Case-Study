# ML-DL-Case-Study

Cross-age HAR: train on younger adults (HARTH + RealWorld HAR), evaluate
zero-shot on older adults (HAR70+).

## Layout

```
harth/  har70plus/       raw data
Real world HAR/          raw data, accelerometer thigh + waist only (see below)
preprocessing/           shared by every model
  src/                   steps 01-05, config.py, evaluate.py
  docs/                  PIPELINE_AND_RESULTS.md: decisions, protocol, results
  processed/             generated by 01-05 (git-ignored): windows.npz, folds.csv, scalers.json
LSTM/                    LSTM model (06_train_lstm.py, lstm_config.py)
```

## Data

| folder | dataset | subjects | what is included |
|---|---|---|---|
| `harth/` | HARTH | 22 younger adults | complete |
| `har70plus/` | HAR70+ | 18 adults aged 70–95 | complete |
| `Real world HAR/` | RealWorld HAR 2016 (Univ. Mannheim) | 15 younger adults | accelerometer, thigh + waist, all 8 activities (263 CSVs, unmodified) |

RealWorld HAR originally has 7 body positions and several sensors; only the
accelerometer files of the two positions the pipeline uses are kept here.
Activities outside the common label set (running, jumping) are kept in the
raw files and dropped in `preprocessing/src/04_labels.py`.
`Real world HAR/download_realworld_acc.command` re-downloads the data from
the original source (it fetches all 7 positions; only thigh + waist are used).

Source and citation: T. Sztyler and H. Stuckenschmidt, "On-body Localization
of Wearable Devices: An Investigation of Position-Aware Activity
Recognition", IEEE PerCom 2016.
https://www.uni-mannheim.de/dws/research/projects/activity-recognition/dataset/dataset-realworld/

## Shared preprocessing (`preprocessing/`)

Steps 01–05 load all three datasets, map them to six common labels
(walking, stairs_up, stairs_down, standing, sitting, lying), cut 128-sample
windows (2.56 s at 50 Hz) and assign subject-grouped 5-fold CV folds.
HAR70+ is test only (fold −1). Every model should use these windows, folds
and `evaluate.score()` so the results are comparable.

```bash
pip install -r requirements.txt
python preprocessing/src/01_load_harth.py   # then 02 ... 05 in order
```

How to load the windows in your own model, and the evaluation rules:
section 3 of [`preprocessing/docs/PIPELINE_AND_RESULTS.md`](preprocessing/docs/PIPELINE_AND_RESULTS.md).
